📖 Elemen HTML Penting

HTML adalah fondasi dari semua halaman web. Tabel berikut menampilkan elemen-elemen HTML yang sering digunakan beserta penjelasannya. Klik tombol "Preview" untuk melihat contoh hasilnya!

Elemen HTML Deskripsi
<!DOCTYPE html> Deklarasi untuk memberitahu browser bahwa ini adalah dokumen HTML5.
<html> Elemen akar (root) yang membungkus seluruh konten halaman web.
<head> Wadah metadata (informasi tentang data) yang tidak tampil di browser.
<meta> Mendefinisikan metadata seperti karakter set, deskripsi, dan keyword SEO.
<link> Menghubungkan dokumen dengan sumber eksternal (paling sering CSS).
<style> Digunakan untuk menulis kode CSS langsung di dalam file HTML.
<script> Menyisipkan atau merujuk ke kode JavaScript.
<title> Menentukan judul halaman yang muncul di tab browser.
<body> Berisi semua konten visual seperti teks, gambar, dan tombol.
<base> Menentukan URL dasar untuk semua link relatif dalam dokumen.
<source> Menentukan sumber media untuk elemen <video> atau <audio>. Tidak tampil sendiri.
<summary> Judul yang diklik untuk membuka elemen <details>. Hanya tampil bersama details.
<figcaption> Keterangan untuk elemen <figure>. Hanya tampil bersama figure.
<option> Item pilihan di dalam <select> atau <datalist>. Hanya tampil di dropdown.
<li> Item daftar yang diletakkan di dalam <ol> atau <ul>.
<thead> Bagian kepala tabel yang berisi header/judul kolom.
<tbody> Bagian tubuh tabel yang berisi data utama.
<tfoot> Bagian kaki tabel, biasanya untuk ringkasan atau total.
<tr> Baris tabel (table row).
<canvas> Area untuk menggambar grafik, animasi, atau game menggunakan JavaScript.
<dialog> Membuat kotak dialog atau modal bawaan HTML. Butuh JavaScript untuk menampilkan.
<datalist> Daftar saran untuk elemen input. Membutuhkan interaksi dengan input.
<figure> Wadah untuk gambar, diagram, atau ilustrasi. Membutuhkan konten di dalamnya.
<svg> Membuat gambar vektor yang dapat diperbesar tanpa pecah. Butuh kode SVG khusus.
<blockquote> Menandai teks yang merupakan kutipan dari sumber lain.
<code> Menampilkan potongan kode komputer atau pemrograman.
<noscript> Konten yang tampil jika JavaScript dinonaktifkan di browser.
<template> Menyimpan template HTML yang belum dirender. Tidak tampil di halaman.
<meter> Menampilkan nilai dalam rentang tertentu (gauge/indikator).
<time> Menandai tanggal atau waktu untuk mesin pencari.
<sup> Membuat teks pangkat (superscript).
<sub> Membuat teks indeks (subscript).
<q> Membuat kutipan pendek di dalam paragraf.
<abbr> Mendefinisikan singkatan atau akronim.
<kbd> Menampilkan input keyboard.
Elemen HTML Deskripsi Aksi
<h1> - <h6> Heading / judul halaman (h1 terbesar, h6 terkecil).
<p> Paragraf untuk teks biasa.
<a> Link untuk navigasi ke halaman lain atau lokasi.
<img> Menyisipkan gambar ke halaman.
<button> Membuat tombol yang dapat diklik.
<input> Field input untuk pengguna memasukkan data (text, email, password, dll).
<div> Pembungkus generic untuk mengelompokkan elemen lain.
<span> Pembungkus inline untuk teks atau elemen kecil.
<ul> <li> Daftar tidak terurut (bullet list).
<ol> <li> Daftar terurut (numbered list).
<strong> Teks penting (biasanya ditampilkan tebal, semantic).
<em> Teks dengan penekanan (biasanya italic, semantic).
<br> Penyisip line break / garis baru.
<hr> Garis pemisah horizontal.
<form> Wrapper untuk input field dan tombol submit.
<label> Label untuk input field agar lebih accessible.
<textarea> Field input multi-baris untuk teks panjang.
<select> <option> Dropdown menu untuk memilih satu opsi dari banyak pilihan.
<header> Bagian kepala halaman, biasanya berisi logo dan menu navigasi.
<nav> Bagian navigasi halaman.
<main> Konten utama halaman.
<footer> Bagian kaki halaman, biasanya berisi info tambahan dan copyright.
<article> Konten independen yang bisa berdiri sendiri (berita, blog post).
<section> Bagian dari halaman yang memiliki tema atau topik tertentu.
<aside> Konten sampingan (sidebar, widget, iklan).
<table> <tr> <td> Membuat tabel dengan baris dan kolom.
<th> Sel header tabel (table header), biasanya ditampilkan tebal.
<td> Sel data tabel (table data) untuk konten reguler.
<video> Menyisipkan video yang dapat diputar langsung di halaman.
<audio> Menyisipkan file audio yang dapat diputar di halaman.
<iframe> Menampilkan halaman web lain di dalam halaman.
<details> Membuat konten yang bisa dibuka dan ditutup.
<progress> Menampilkan progress bar.
<mark> Menyorot teks seperti stabilo.

🎨 Properti CSS Penting

CSS digunakan untuk mengatur gaya dan tata letak halaman web. Klik "Preview" untuk melihat contoh penerapan properti CSS!

Properti CSS Fungsi / Deskripsi
z-index Mengatur urutan lapisan elemen.
top, right, bottom, left Mengatur jarak dari tepi dalam positioning. Butuh properti position.
grid-template-columns Menentukan jumlah dan lebar kolom dalam CSS Grid.
min-width Menentukan lebar minimum elemen.
max-width Menentukan lebar maksimum elemen.
min-height Menentukan tinggi minimum elemen.
max-height Menentukan tinggi maksimum elemen.
font-family Mengatur jenis font yang digunakan (Arial, Times New Roman, dll).
line-height Mengatur tinggi baris teks.
letter-spacing Mengatur jarak antar huruf.
word-spacing Mengatur jarak antar kata.
white-space Mengatur penanganan spasi dan line break.
word-break Mengatur pemotongan kata saat overflow.
text-overflow Menentukan tampilan teks yang terpotong.
background-size Mengatur ukuran gambar latar (cover, contain).
background-repeat Mengatur apakah gambar latar diulang atau tidak.
background-position Mengatur posisi awal gambar latar.
background-attachment Menentukan apakah background ikut scroll atau tetap (fixed).
outline Garis di luar border (biasanya untuk fokus aksesibilitas).
border-collapse Mengatur apakah garis tepi tabel digabung atau dipisah.
border-style Mengatur jenis garis (solid, dashed, dotted).
clip-path Memotong elemen menjadi bentuk tertentu (lingkaran, poligon).
backdrop-filter Efek blur pada area di belakang elemen (efek kaca).
mix-blend-mode Menentukan bagaimana konten elemen bercampur dengan latar belakang.
mask-image Menyembunyikan bagian elemen berdasarkan gambar masker.
column-count Membagi teks menjadi beberapa kolom seperti koran.
transform-origin Menentukan titik pusat dari transformasi elemen.
animation Menerapkan animasi yang dibuat dengan @keyframes.
transition-duration Menentukan berapa lama transisi berlangsung.
transition-delay Menentukan waktu tunggu sebelum transisi dimulai.
transition-timing-function Mengatur kurva kecepatan transisi (ease-in, linear, dll).
perspective Memberikan efek kedalaman 3D pada elemen.
backface-visibility Menentukan apakah sisi belakang elemen terlihat saat diputar.
scroll-behavior Mengatur apakah scroll internal berlangsung halus (smooth).
scroll-snap-type Mengunci posisi scroll pada titik tertentu (efek slider).
overscroll-behavior Mengontrol apa yang terjadi saat batas scroll tercapai.
user-select Mengatur apakah teks dapat dipilih pengguna.
pointer-events Mengatur apakah elemen merespon klik/sentuhan atau tidak.
resize Menentukan apakah elemen bisa diubah ukurannya oleh pengguna.
accent-color Mengatur warna utama kontrol form (checkbox/radio).
caret-color Mengatur warna kursor pengetikan di input teks.
object-fit Mengatur bagaimana gambar/video menyesuaikan ukuran wadah.
object-position Menentukan posisi gambar/video dalam wadah.
aspect-ratio Menentukan rasio lebar dan tinggi elemen.
box-decoration-break Mengontrol tampilan dekorasi saat elemen terpecah di baris baru.
isolation Mengontrol konteks pencampuran elemen.
contain Membatasi pengaruh rendering elemen.
will-change Memberitahu browser properti apa yang akan berubah untuk optimasi performa.
visibility Menyembunyikan elemen tanpa menghilangkan ruangnya.
content Digunakan dengan pseudo-element (:before/:after) untuk menyisipkan konten.
counter-reset Membuat atau mengatur ulang variabel counter (untuk penomoran otomatis).
quotes Menentukan tanda kutip mana yang digunakan untuk elemen <q>.
Properti CSS Fungsi / Deskripsi Aksi
color Mengatur warna teks.
background-color Mengatur warna latar belakang elemen.
font-size Mengatur ukuran font teks.
font-weight Mengatur ketebalan font (normal, bold, 100-900).
text-align Menyelaraskan teks (left, center, right, justify).
text-decoration Menambah dekorasi teks (underline, overline, line-through).
margin Mengatur jarak luar elemen dari elemen sekitarnya.
padding Mengatur jarak dalam elemen dari tepi border.
border Menambah garis tepi pada elemen.
width Mengatur lebar elemen.
height Mengatur tinggi elemen.
display Mengatur cara elemen ditampilkan (block, inline, flex, grid).
position Mengatur posisi elemen (static, relative, absolute, fixed).
flex-direction Menentukan arah item dalam flexbox (row, column).
justify-content Menyelaraskan item secara horizontal dalam flexbox.
align-items Menyelaraskan item secara vertikal dalam flexbox.
gap Mengatur jarak antara item dalam flexbox atau grid.
border-radius Membuat sudut elemen menjadi melengkung (rounded).
box-shadow Memberikan efek bayangan pada elemen.
opacity Mengatur tingkat transparansi elemen.
cursor Mengubah bentuk kursor saat berada di atas elemen.
filter Efek visual seperti blur, grayscale, atau brightness.
transform Mengubah bentuk/posisi elemen (rotate, scale, translate, skew).
transition Membuat perubahan properti menjadi halus (animasi transisi).
text-shadow Memberikan bayangan pada teks.
background-image Mengatur gambar latar belakang.
overflow Mengatur konten yang melebihi ukuran elemen.
z-index Mengatur urutan lapisan elemen.
